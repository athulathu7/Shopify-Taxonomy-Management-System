Shopify Taxonomy Management System

This project is a Django-based Shopify Product Taxonomy Classification System developed to automate and simplify the process of classifying large product catalogues into the appropriate categories defined by the Shopify Product Taxonomy. The application allows users to import product data from Excel files and processes product information such as title, description, product type, brand, and image information to identify the most relevant Shopify category. The system includes a structured Shopify taxonomy database with 14,606 categories, category hierarchy handling, attribute and value detection, confidence score generation, alternative category suggestions, and support for products with or without images. It also handles missing product information and provides a manual review workflow for products where the automated classification requires verification.

The application is designed with scalability and usability in mind, including batch processing functionality capable of handling 10,000+ products, allowing large catalogues to be processed in manageable batches. A professional dashboard provides an overview of total products, classified products, pending products, and products requiring manual review, while the product catalogue provides search and pagination for efficiently managing large datasets. The backend is built using Python, Django, and MySQL, with Pandas used for Excel and product-data processing, while HTML, CSS, JavaScript, and Bootstrap are used to create the frontend interface. Overall, the project provides an end-to-end solution for automated Shopify product classification, reducing manual categorization effort and making large-scale product catalogue management more efficient, structured, and reliable.
